CAR ZONE - مشروع تصميم موقع ويب
==============================

ترتيب المشروع بسيط مثل المشروع المرجعي:

index.html            الصفحة الرئيسية
html/                 جميع الصفحات الأخرى
css/                  ملفات CSS + Bootstrap
js/                   ملفات JavaScript + jQuery + Bootstrap
img/                  الصور
vedio/                مجلد الفيديو
font/                  مجلد الخطوط عند الحاجة

الصفحات:
1- الرئيسية
2- السيارات
3- من نحن
4- تواصل معنا
5- تسجيل الدخول
6- إنشاء حساب

المتطلبات الموجودة:
- HTML Layout: header, nav, section, aside, footer
- عناصر HTML: عناوين، فقرات، قوائم، صور ونماذج
- أكثر من 5 صفحات
- Font Awesome في صفحة التواصل
- تسجيل دخول وإنشاء حساب مع Validation
- Bootstrap Carousel في الصفحة الرئيسية
- Grid و Flexbox
- Media Queries للتجاوب
- Bootstrap Modal عدد 2
- Ajax لتحميل محتوى المودالين
- Bootstrap محلي داخل المشروع
- jQuery محلي داخل المشروع

ملاحظة:
لم يتم عمل جدول لأن المطلوب منك كان عدم إضافة الجداول.

لتشغيل Ajax بشكل صحيح:
شغّل START_PROJECT.bat ثم افتح الموقع من المتصفح.
